# Primeiro Projeto

Use este arquivo para iniciar seu primeiro sistema com a equipe de agentes.

## Ideia inicial

Criar um sistema que:

- tenha usuarios;
- resolva um problema real;
- use IA ou ML em uma parte especifica;
- possa ser entregue em uma primeira versao simples.

## Proximo comando sugerido

Copie o texto abaixo e use com o agente Coordenador:

```text
Atue como meu Agente Coordenador.

Quero criar o seguinte sistema:
[descreva aqui sua ideia]

Monte um plano de execucao usando minha equipe de agentes.
Defina quais agentes devem atuar, em que ordem, quais tarefas cada um deve executar e qual deve ser o primeiro MVP.
```
